# Focus Deck (study)

**Focus Deck** is an original, open-source all-in-one study & productivity web app (PWA-ready foundation). It combines common feature categories inspired by popular productivity apps — **timetable/planner, mind maps, focus timer, and notes/tasks** — with **everything unlocked for free** (no ads, no paywalls, no artificial limits).

> This project is an independent, original implementation. It does **not** copy code/assets/branding from proprietary apps.

## Feature modules (all free)
- **Timetable / Planner:** weekly schedule grid, add/edit entries, quick AI-style local generator, export/print, PDF-friendly options (title/orientation) — unlimited.
- **Mind Map:** create nodes/branches, edit/rename/delete, multiple maps, export to JSON — no locked templates/themes.
- **Focus:** focus timer (Pomodoro/custom), session log, streak/stats, personal blocklist/reminders — no “pro pass” required.
- **Notes & Tasks:** pages/notes, checklists/tasks, simple tables — unlimited.
- **Privacy-first:** data stored locally in your browser (localStorage). No accounts required.
